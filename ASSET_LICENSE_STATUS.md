# Asset policy and status

The repository intentionally excludes the creator's privately owned image, audio, and other embedded data assets. The HTML refers to them under `private-assets/`, but that directory is not committed.

This means the public repository is a source-code release, not a complete, standalone playable distribution. The game will require the owner's private asset files to be restored in a local `private-assets/` directory to run as originally intended.

Do not commit the private assets unless the owner later decides to publish them under a separate explicit licence. Check that every excluded file is actually owned by the creator before relying on this policy.
